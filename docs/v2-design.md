# DeepWord 2.0 设计（设计稿：Phase A / B 均已实现）

状态：**Phase A（`1.0.1`）与 Phase B（`1.1.0`）均已实现**（Phase A：provider 管理 + 本地代理 + 流式 + 数据迁移；Phase B：学习流程 + 6 题型 + 薄弱分析 + AI 反馈 + 浏览器 TTS）。
本文件是行为与决策的唯一出处；实现细节见 [规格](spec.md) 与 [架构](architecture.md)。

## 目标

- 六种背单词方式混合出题，不再让用户选模式；按薄弱分析自适应当题。
- 支持多份 OpenAI 兼容 / Anthropic 兼容 provider 配置。
- 答错时调 AI 讲解。
- 保持本地优先：数据在本机，无账号、无后端。

## 版本

- 应用版本：Phase A → `1.0.1`；Phase B → `1.1.0`。
- 数据版本：`1 → 2`（结构变化，Phase A 迁移）。
- 提示词：drill 的 `PROMPT_VERSION=v1` 不变；新增 `FEEDBACK_PROMPT_VERSION=v1`（Phase B）。

## Provider 管理

- 可保存多份配置，同时只有一个「当前使用」。
- 每份字段：名称、协议（OpenAI 兼容 / Anthropic）、厂商、Base URL、API Key、模型白名单、默认 model、温度、最大输出、思考开关。
- 拉取模型列表：弹窗勾选保留的 model。首次全选；再次拉取保留旧勾选；已下架标「已下线」；始终可手动填 model id。
- 测试连接：发一次极小请求，显示成功/失败、延迟、可操作原因。
- 思考开关：设置页显示该模型实际是否支持关闭。
- 出题与讲解都用「当前使用」的配置，暂不按用途分路。

## 学习流程

- 学习页两个 tab：学习、闪卡。
- 一轮 = 新词 N 个（默认 1，可调 1～10；每词 4～8 题，默认 6）→ 复习 4～6 词（题量 `词数～2×词数`，默认 10）→ 小结 → 点「继续」下一轮。
- 新词先过闪卡闸门：不认识 / 掌握。点掌握则翻面显示释义，追问确认；确认即标掌握，永久不再学、不再复习。
- 不认识：直接出题，无独立教学卡；第 1 题反馈附完整词条信息。
- 闪卡 tab：已学词快速自查，规则同上；点不认识则排下一轮复习优先。
- 掌握判定：连续 3 次全对且覆盖 ≥2 技能 + 14 天无错 + 分布 ≥2 轮次；可手动取消掌握。
- 取消间隔重复排程：复习每轮必做，按薄弱度选词。

## 题型（6 技能）

`en2zh`、`zh2en`、`spell`、`listen`、`sentence`、`translate`。

- 题目全部本地生成，离线可用。
- 互译每题都调 LLM 判分（流式），三档 `perfect` / `good` / `poor`；`poor` 必须看完讲解才能下一题。
- 听音题用浏览器 TTS；无可用英文语音则不出听音题。
- 未配置 AI 则不出互译题。

## 薄弱分析

- 6 维度，从作答记录现算。
- 仪表盘展示各技能正确率、最弱词、建议重点。
- 复习选词与题目类型按薄弱度优先。

## AI 反馈

- 答错：流式讲解（错因 + 记忆点 + 改进），不自动跳题。
- 答对：本地鼓励语，3 秒后自动下一题（可设 0 = 手动）。
- 互译：每题判分 + 改进建议；完美给鼓励。
- 讲解写入作答记录，成绩单与错题本可回看。
- 失败降级为本地解析，不阻塞作答。

## 数据与迁移

- 数据仍只存本机 localStorage。
- 新增 provider 配置、练习设置、作答新字段。
- 旧数据自动迁移；旧备份可导入；API Key 仍只存本机，导出默认不含。
- 本地代理只转发请求，不保存 Key。
- Phase B 只做**可缺省的新增字段**（`mastery` / `reviewPriority`，`session` 与 `attempt` 追加可选字段），数据版本保持 `2`，旧 v2 数据可直接读取。

## 风险

- 各模型思考参数行为不一：尽力关，失败则如实显示「未生效」。
- 浏览器 TTS 语音可用性不一：能力检测，缺语音隐藏听音题。
- 互译每题一次 LLM 调用：成本与延迟高，占轮次比例 ≤1/3。
