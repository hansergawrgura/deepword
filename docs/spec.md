# 产品规格（Spec）

「词渊 DeepWord」产品需求与验收规格。本文是**行为契约**：界面文案可以调整，但表中描述的判定规则、默认值、边界行为属于验收标准；变更需同步 CHANGELOG 与版本规格。

---

## 1. 产品定位

面向中文母语的英语学习者（CET-4/6、考研、雅思备考）的**本地优先**背单词工具：闪卡做间隔重复，自动积累错题档案，用用户自己的大模型针对每个错词的历史错误**重新命题**，形成「学 → 错 → 针对性练 → 再学」的闭环。所有数据留在本机。

**不做**：账号系统、云同步、社交/排行榜、词库内容审核、自动抓取词典。

## 3. 功能规格

### 3.1 单词与词库

| 需求 | 规格 |
| --- | --- |
| 首次启动 | 自动载入内置词库 190 词，全部为 `new` 状态，无任何学习记录 |
| 字段 | `term`（必填，≤64）、`meaning`（必填，≤300）、`phonetic`、`partOfSpeech`、`example`、`exampleTranslation`、`tags`（≤6，去重） |
| 唯一性 | `term` 不区分大小写唯一；数据清洗同时按 `id` 去重 |
| 增删改 | 重复词条拒绝并提示；删除单词同时清理其卡片、错题与作答记录（二次确认） |
| 搜索 | 匹配 `term` / `meaning` / `tags`，不区分大小写 |
| 筛选 | 全部 / 新词 / 学习中 / 复习中 / 已掌握 / 错词（含筛选计数） |
| 排序 | 最近添加 / 字母序 / 错误最多 / 最先到期 |
| 分页 | 每次渲染 60 条，可「加载更多」 |
| 导入词库 | JSON 数组，或含 `words` 数组的对象；字段非法条目忽略并在预览中提示；重复词条跳过；导入后 toast 报告新增/跳过数量；<br>非法 JSON 时禁用导入按钮并给出格式错误 |
| 导出词库 | 导出纯单词字段（不含学习状态）为 JSON，文件名带日期 |
| 上限 | `MAX_WORDS = 10 000` |

### 3.2 闪卡与间隔重复

> **1.1.0 起**：学习页改为「闸门 + 多模块出题 + 薄弱度复习」（见 §3.9）。旧版「学习队列 + 三阶段学习页（四档自评）」已移除，
> 下表描述的 SRS 排程算法**只保留在数据层**（用于卡片进度、掌握度分布与统计），**复习选词不再依赖到期时间**；
> 闪卡 tab 改为「不认识 / 掌握」两档自查（见 §3.9）。

| 评分 | 按钮文案 | 首次/学习阶段间隔 | 复习阶段间隔 | 难度系数 |
| --- | --- | --- | --- | --- |
| `again` | 没记住 | 10 分钟后重来，`lapses+1`，状态 `learning` | 同左 | −0.20 |
| `hard` | 有点模糊 | 1 天 | `interval × 1.2` | −0.12 |
| `good` | 记住了 | 2 天 | `interval × ease` | 不变 |
| `easy` | 太简单了 | 4 天 | `interval × ease × 1.3` | +0.10 |

- 难度系数 `ease ∈ [1.3, 3.0]`；单次间隔上限 180 天；间隔 ≥ 30 天状态为 `mastered`；复习 ≥2 次为 `review`。
- 卡片状态：`new`（reps=0）→ `learning`（首次答对/relearn）→ `review` → `mastered`。
- 卡片推进来源：1.1.0 起由**练习判分**驱动（判对记 `good`、判错记 `again`）；四档自评 action 仍在数据层保留，但界面不再调用。
- 学习队列（学习中 → 到期复习 → 新词；每轮 ≤24 张、新词 ≤10；混合 / 只复习 / 只学新词）：**1.1.0 已移除**（模块 `session.ts` 一并删除），复习选词改由「按薄弱度」决定（见 §3.9）。
- 旧版快捷键（扉页 `Space`/`Enter` 开局；`Space` 翻面、`1`–`4` 评分、`Esc` 结束本轮）：**1.1.0 已移除**；新流程里空格只用于闸门翻面提示。
- 旧版空状态与成绩单（「再来一轮」空状态、「去词库添加 / AI 特训」出口、四档次数成绩单）：**1.1.0 已移除**；新一轮的小结见 §3.9（正确率、技能分布、需要再看一眼的词）。

### 3.3 错题档案

- 每个词最多一份档案：`wrongCount`、`correctStreak`、`firstWrongAt`、`lastWrongAt`、`lastAttemptAt`、`lastExerciseType`、`lastPrompt`（≤300，供 LLM 避免重复出题）。
- 练习题判错记为错（含题型与题干）；判对 `correctStreak+1`。
- 闪卡四档自评的档案规则（`again` 记为错、`hard` 不改档案、`good`/`easy` 连对 +1）仍在数据层保留，但 1.1.0 的界面不再调用四档自评。
- `correctStreak ≥ 2` 视为「已攻克」，错题本中排在未攻克项之后；侧栏与特训页角标只统计未攻克错词。

### 3.4 AI 错题特训

**选词（setup）**

- 默认候选：错题本按错误次数 desc → 最近出错 desc，默认勾选前 8 个；可全选/清空。
- 无错词：空状态 + 「随机从词库选词」（随机 8 个，标题切换为「这轮抽到的词」）；词库为空：提示先去添加。
- 每个候选展示：词、音标、释义、错误次数、最近出错时间、近期正确率。
- 题量 4 / 6 / 8（默认 6）；难度「自适应 / 巩固基础 / 挑战」（默认自适应）。
- 引擎状态：已配置显示协议 + 模型；远端缺 Key 显示金色提示与「前往设置」；可随时「不用大模型，改用本地题库」。

**生成（generating）**

- 分阶段文案（如「正在整理错词与错因…」「正在校验题目…」）、已用秒数、可取消（取消后回到 setup，无脏状态）。
- 失败：展示 `LLMError.message` + 按 code 的可操作建议 + 服务端摘要；操作「重试 / 改用本地题库继续 / 返回调整」。

**作答（quiz）**

- 选择题：选项 3~4 个，键盘 `1`–`4` 选择、`Enter` 判分、判分后 `Enter` 下一题；填空：行内输入，`Enter` 提交。
- 判分：`normalizeAnswer` 后比较；填空命中 `answer` 或任一 `acceptableAnswers` 即正确。
- 判分后立即显示：对/误、你答与正解、中文解析、考查词（可发音）。
- 每题判分立即写回学习记录（卡片按 `good`/`again` 排程、错题档案与每日统计同步更新），双击/重复点击不会重复计数。
- 可随时「结束特训」，按已答部分结算。

**成绩单（result）**

- 正确率、答对/答错/已答/用时、错题复盘（词、释义、你答、正解）、批语；出口「再练一组（保留上次选词与题量）/ 去闪卡复习 / 回首页」。
- 实际题量少于目标时按实际完成（每词最多 2 题所致），文案需说明。

### 3.5 LLM 出题（`PROMPT_VERSION = v1`）

- 题型：`choice` 词义/辨析、`fill` 例句填空、`usage` 用法判断、`correction` 纠错判断（后两者同为选择题）。
- 出题策略：错误次数多、近期正确率低、连续答对少的词优先；若上次错在某题型，优先再考同类；每词 ≤2 题；干扰项同词性/同语义场、禁止「以上都对」类选项。
- 输出严格纯 JSON；解析层容忍代码围栏与前后杂文。
- 校验：`wordId` 必须在输入内；题型合法；选择题选项 3~4 且互不重复、答案精确匹配（归一化唯一命中时修正、容忍 `A.` 类序号）；填空必须含连续下划线、答案唯一非空；`prompt ≤500`、`explanation ≤400`（超长截断）；`difficulty` 取整并限制 1~5；选项打乱；按 `wordId+type+规范化 prompt` 去重。
- 全部不合法 → 报错（`parse`/`empty`），由 UI 回退本地题库。

### 3.6 本地兜底出题

- 输入：所选单词 + 全库错题档案 + 目标题量；永不抛错，词库不足时返回更少题目（可为 0）。
- 选题：错词按错误次数/最近出错优先，先覆盖尽量多不同单词。
- 选择题：词↔义双向交替；选项取自其他真实词条；同词性、拼写/释义相近优先；释义重叠过高视为近义不采用；`answer` 严格等于某选项原文。
- 填空：在例句中按屈折形式（-s/-ed/-ing/双写/y→ies 等）挖空；`acceptableAnswers` 含原形与大小写变体；例句不可用或一词多现时退化为语境句防泄题。
- 字段：`source='local'`、`difficulty` 2–5（错词次数加权）。

### 3.7 今日仪表盘

- 指标：待复习数（按薄弱度挑选的候选词）、新词数、今日学习次数（目标 20）、近七日正确率、连续学习天数（今天未学则从昨天往前数）、今日进度条、错题待攻克前 5、词库掌握度四段分布、28 天热力图（1/5/10/20 次分四档）、最近 5 条作答。
- **薄弱分析面板**（1.1.0）：6 个技能的正确率与作答次数、最弱词（≤5）、建议重点；没有带技能标记的作答时显示引导空态（引导去学习页开一轮）。
  - 面板内的最弱词可点击，但**只能跳到词库首屏**，不能在词库内直接定位到该词条（已知限制）。
- 快捷入口：开始今日学习 / 错题 AI 特训 / 去词库 / 特训指定错词。

### 3.8 设置

**模型连接（多 provider 管理）**

- **列表**：每份配置一张卡片，展示名称、协议、厂商、Base URL、默认模型、模型白名单数量、「当前使用」标记与「缺 Key」提示；操作「编辑 / 删除 / 设为当前」。上限 `MAX_PROVIDERS = 20`，达到上限后禁用新增。
- **新增 / 编辑**：表单字段——名称（≤40，可留空，空名显示为「配置 N」）、协议（OpenAI 兼容 / Anthropic）、厂商（OpenAI / Anthropic / DeepSeek / 通义千问 / Ollama / Kimi / 智谱 GLM / 硅基流动 / 火山方舟 Ark / MiniMax / 其他自定义）、Base URL（仅接受 http(s) 且主机名非空；选择厂商可「填入预设」；Anthropic 协议可填厂商前缀（火山方舟 `/api/coding`、DeepSeek `/anthropic`）或版本层（`/v1`），程序自动补齐 `/v1/messages`；Anthropic 兼容网关同时携带 `x-api-key` 与 `Authorization: Bearer`，官方主机只发 `x-api-key`）、API Key（密码框、可切换显示；本地端点可留空，Anthropic 必填）、默认 model（可自由输入 + 白名单建议）、模型白名单（≤`MAX_MODELS_PER_PROVIDER = 300`）、温度 0–1.5、最大输出 Tokens 64–32000、思考开关（「尽量关闭」/「交给服务商默认」）。
- **模型列表弹窗**：经本地代理向服务商拉取模型列表，弹窗内可搜索、全选/清空、重新拉取、手动添加 model id（回车加入）。
  - 首次拉取且白名单为空 → 默认全选；
  - 已有白名单再次拉取 → 保留原勾选，服务端新出现的模型默认不勾选；
  - 本次未返回、但此前已勾选的旧模型保留并标「已下线」；服务端 `lifecycle` 为 deprecated/retired 的模型同样标「已下线」；
  - 确认后按列表顺序写回白名单；默认 model 不受白名单限制。
- **连通性测试**：用表单当前值发一次极小请求（`max_tokens: 1`，强制关闭思考），只看响应是否成功（**空内容也算成功**）；成功显示延迟与模型，失败显示可操作原因；测试不修改已保存配置。
- **切换与删除**：任意时刻只有 `activeProviderId` 指向的一份配置生效；删除当前配置后自动切换到列表第一份，列表为空时 AI 功能退回本地题库。
- **思考开关**：选「尽量关闭」时按厂商注入关闭思考参数（Anthropic / DeepSeek / GLM / 火山方舟 Ark / Kimi 用 `thinking:{type:'disabled'}`，Kimi K3 系列用 `reasoning_effort:'low'`；通义千问 / 硅基流动用 `enable_thinking:false`；OpenAI 用 `reasoning_effort:'minimal'`；Ollama 用 `reasoning_effort:'none'`；MiniMax / 自定义不发）；上游以 400 点名思考参数时去掉该参数重试一次。部分模型不支持关闭思考，界面需提示「可能不生效」。
- 编辑表单维护本地草稿，保存后才写入数据；取消不产生修改；导入备份后若正在编辑的配置已不存在，表单自动收起。

**数据管理**：本机占用体积、词条、作答数量与配置份数；导出完整备份（`version=2`，可选包含 Key，默认关闭并提示风险）/ 导入备份（覆盖词库、记录与配置，二次确认；备份中缺失的 Key 按协议 + Base URL 继承本机已有 Key）；清空学习进度（保留词库/模型配置/练习设置/主题，二次确认）；恢复初始示例词库（保留模型配置与主题，二次确认）。

**练习设置（1.1.0）**：每轮新词数（1~10，默认 1）、每词题量（4~8，默认 6）、每轮复习词数（4~6，默认 6）、每轮复习题量（落在 `词数～2×词数`，默认 10）、答对后自动跳转（3 秒 / 5 秒 / 手动 = 0）、自动讲解开关、发音语速（0.5~2）与英文语音选择、发音自动播放；所有改动即时生效（无「保存」按钮），写入后按同一套清洗口径归一（改复习词数时复习题量自动拉回合法区间）。

- 「自动讲解」开关只落盘保存：答错的讲解目前**总会生成**，该开关暂未参与讲解的触发判断（已知限制）。

**外观**：昼读/夜读（持久化到数据并作用于 `<html data-theme>`，同步 `theme-color`）。

**关于**：版本、出题引擎、当前配置（名称 + 厂商 + 模型）、思考开关状态、提示词版本、记忆算法、存储位置、隐私说明。

### 3.9 学习流程（1.1.0）

**两个 tab**

| tab | 用途 |
| --- | --- |
| 学习 | 走完整的一轮：新词闸门 → 新词出题 → 复习出题 → 小结 → 继续下一轮 |
| 闪卡 | 已学词快速自查：点「不认识」排下一轮复习优先，点「掌握」翻面确认后永久掌握 |

**状态机（一轮的推进顺序）**

```
plan → gate → new → review → summary/done → 继续下一轮
```

| 阶段 | 进入条件 | 离开条件 |
| --- | --- | --- |
| `plan`（概览，UI 状态：`data.session` 为空） | 没有未完成的会话，或点「结束本轮」 | 点「开始一轮」→ `planRound` 选出新词与复习词 |
| `gate`（闸门） | 本轮有尚未处理的新词 | 点「不认识」→ `new`；点「掌握」→ 翻面追问，确认 → 标记掌握并进入下一个新词的 `gate`（没有则 `review`），点「再想想」→ `new` |
| `new`（新词出题） | 某个新词过闸门后 | 该新词的题目答完 → 下一个新词的 `gate`，没有则 `review` |
| `review`（复习出题） | 所有新词处理完 | 该阶段题目答完 → `summary` |
| `summary` / `done`（小结） | 复习阶段答完 | 点「继续」→ 下一轮 `plan`；点「结束本轮」→ 清空会话回概览 |

- 复习**每轮必做**，**取消间隔重复排程**：复习词按薄弱度挑选（闪卡「不认识」标记优先，其次薄弱度降序），新词与已掌握词不进入复习列表。
- 一轮的进度（阶段、题目、当前下标、逐题结果与讲解）持久化在本地（`data.session`），中途退出后可恢复；轮次序号随轮次递增。

**一轮的题量**

| 项 | 规则 | 默认 |
| --- | --- | --- |
| 每轮新词数 | 1~10（`practice.newWordsPerRound`） | 1 |
| 每词题量（新词） | 4~8（`practice.questionsPerNewWord`） | 6 |
| 每轮复习词数 | 4~6（`practice.reviewWordsPerRound`） | 6 |
| 每轮复习题量 | 落在 `复习词数 ～ 2×复习词数` | 10 |

- 同一新词在一轮内不会重复出同一技能（同词同技能一轮内不重复）；新词优先覆盖全部 6 种题型。
- 互译题占本轮题量的比例 ≤ 1/3；无可用英文语音时不出听音题；未配置 AI 时不出互译题（此时由其余技能补齐题量）。

**新词闸门（gate）**

- 先问「不认识 / 掌握」；点「掌握」翻面显示释义并追问确认（确认 / 再想想），确认即标掌握，永久不再学习与复习。
- 点「不认识」直接出题，**无独立教学卡**；该新词第 1 题的反馈附完整词条信息（音标、词性、释义、例句与翻译、标签）。
- 本轮有多个新词时，**每个新词各走一遍闸门**，按顺序推进。

**判分与写回**

- 选择题 / 拼写题：本地判分（`checkAnswer`），拼写容忍大小写、首尾标点与空格，并接受等价答案表。
- 互译题：由 AI 判三档 `perfect` / `good` / `poor`，`perfect` / `good` 记为正确，`poor` 记为错误。
- 每判一题立即写回作答记录（`attempts`）：带上 `skill` / `roundId` / `verdict` / `latencyMs` / `aiFeedback` / `aiImprovement` / `aiStatus`，并同步错题档案、每日统计与 SRS 卡片排程。
- 同一轮的逐题结果（含讲解）保存在会话里，供本轮小结回看。

**掌握判定**

- 四个条件同时满足才自动标记掌握：连续 3 次练习作答全对、这几次覆盖 ≥2 个技能、14 天无错、这几次分布在 ≥2 个轮次。
- 手动掌握（闸门确认）立即生效；已掌握的词可手动取消掌握，取消后回到复习队列。

**互译三档与流式**

- 协议：模型首行输出 `VERDICT: perfect|good|poor`，空行后是讲解正文；流式过程中一解析出档位就立即回显，不必等整段结束。
- 档位含义：`perfect` 意思完整准确；`good` 基本正确但有小瑕疵；`poor` 关键信息错误或遗漏。留白或答非所问判 `poor`。
- 判为 `poor` 时**必须先点「我看完了」**才能进入下一题；`perfect` / `good` 给鼓励语。

**反馈与自动跳转**

- 答错：流式 AI 讲解（错因 + 记忆点 + 改进），**不自动跳题**；AI 不可用、超时或出错时降级为本地解析，作答不中断。
- 答对：本地鼓励语，按设置自动跳下一题（默认 3 秒；设为 0 则手动）。
- 讲解与改进建议写入作答记录（截断 ≤400），本轮小结与错题本可回看；讲解按纯文本渲染，不含 API Key。

### 3.10 题型与薄弱分析

**6 技能题型**

| skill | 题型 | 说明 |
| --- | --- | --- |
| `en2zh` | 选择（英选中） | 看英文选中文释义 |
| `zh2en` | 选择（中选英） | 看中文释义选英文单词 |
| `spell` | 填空（拼写） | 看释义与音标写单词 |
| `listen` | 选择（听音） | 听发音选释义（浏览器 TTS） |
| `sentence` | 选择（连词成句） | 例句挖空选词 |
| `translate` | 互译（中英互译） | 自由作答，AI 三档判分 |

**出题规则**

- 题目全部本地生成、离线可用；干扰项优先同词性、排除近义释义（避免双解），选项 3~4 个且答案唯一。
- 选项不足时按 2 个选项出题；词库只有 1 个词时该技能不出题。
- 每个技能最多准备 2 套题干变体，用于在同一轮内补齐题量且不重复。
- 题目与解析长度上限：`prompt ≤ 500`、`explanation ≤ 400`。

**降级**

| 条件 | 表现 |
| --- | --- |
| 浏览器没有可用英文语音 | 不出听音题，其余题型照常 |
| 未配置可用 AI（或代理未启动） | 不出互译题；答错讲解降级为本地解析，判分与作答不中断 |
| 词条缺释义 / 例句 | 对应技能不出题（例句题需要可挖空的例句） |
| 词库太小 | 选项不足时减少选项数，仍不可出则跳过该技能 |

**薄弱分析（6 维度）**

- 数据源：只统计带 `skill` 标记的**练习作答**（闪卡自评与错题特训的旧题不带 `skill`，不计入）；一律**现算**，不落库。
- 技能维度：固定 6 项，顺序同 `SKILLS`（英译中 / 中译英 / 拼写 / 听音 / 例句 / 互译）；每项给出作答次数与正确率（无作答显示 `—`）。
- 最弱技能：正确率最低者；同分时作答次数少的更弱，再同分按固定顺序。
- 最弱词：**只含有过错的词**（没错过的词没有复习价值），最多展示 5 条，按薄弱度降序；掌握词不参与。
- 单词薄弱度 = 错误次数 × 12 + (100 − 近期正确率) × 0.25 + 最近作答久未复习的天数 × 0.5（上限 30 天）+ 闪卡「不认识」标记加权 20；掌握词记 0。
- 建议重点：一句话，指出最弱技能（与次弱技能接近时并列点名）、建议补练的题量，以及最该重练的词。

## 4. 数据与安全规格

- 存储键 `deepword:data:v2`，`DATA_VERSION = 2`；旧键 `deepword:data:v1` 仅作为迁移来源，迁移成功后保留（不清除）一个 MINOR 版本周期。
- 1.1.0 只新增**可缺省**字段（`AppData.mastery` / `AppData.reviewPriority` / `AppData.session`，`Attempt` 追加 `skill` / `verdict` / `roundId` 等可选字段），**不触发数据迁移**：`DATA_VERSION` 仍为 `2`，旧 v2 数据直接可读。
- v1 自动迁移：读取时凡 `version === 1` 或「无 `providers` 但有旧 `settings`」的数据，自动迁移为 v2——旧的单份 `settings` 转为一份名为「默认配置」的 provider（厂商按 Base URL 推断），补默认 `practice` / `session`，然后走全量清洗。
- 上限：`MAX_ATTEMPTS = 3000` 条作答记录，每日统计保留 400 天；`MAX_PROVIDERS = 20` 份配置，每份模型白名单 ≤`MAX_MODELS_PER_PROVIDER = 300`。
- 持久化：数据变化 250ms 防抖写入；页面隐藏/离开前强制落盘。
- 损坏恢复：读取失败时提示一次、把原始文本写入 `deepword:data:v2:corrupt:<timestamp>`、载入示例词库（读旧键失败时写 `deepword:data:v1:corrupt:<timestamp>`）；`words` 存在但类型非法同样按损坏处理。
- 配额满：给出可操作提示（导出备份后清理记录），同一错误不重复刷屏。
- 备份：导出格式 `version=2`，默认不含 Key；导入接受 v2 / v1 备份（v1 自动迁移）或裸 `AppData`，覆盖当前词库与记录，缺失的 Key 按 Base URL 继承本机配置。
- Key 安全：仅存本机 localStorage；导出默认不含；不出现在 DOM、控制台、URL、异常栈；本地代理不保存、不记录 Key 与请求内容。
- 代理安全：只监听回环地址；仅允许 `http/https` 上游；只转发头白名单并剥离 `Origin` / `Referer` / `Cookie`；不跟随重定向、不缓存；请求体 ≤1 MB；上游连接超时 20s、总超时 90s。
- 内容安全：模型输出经严格校验，题干与解析按纯文本渲染（不执行 HTML）。
