# 产品规格（Spec）

「词渊 DeepWord」产品需求与验收规格。本文是**行为契约**：界面文案可以调整，但表中描述的判定规则、默认值、边界行为属于验收标准；变更需同步 CHANGELOG 与版本规格。

---

## 1. 产品定位

面向中文母语的英语学习者（CET-4/6、考研、雅思备考）的**本地优先**背单词工具：闪卡做间隔重复，自动积累错题档案，用用户自己的大模型针对每个错词的历史错误**重新命题**，形成「学 → 错 → 针对性练 → 再学」的闭环。所有数据留在本机。

**不做**：账号系统、云同步、社交/排行榜、词库内容审核、自动抓取词典。

## 3. 功能规格

### 3.1 单词与词库

| 需求 | 规格 |
| --- | --- |
| 首次启动 | 自动载入内置词库 190 词，全部为 `new` 状态，无任何学习记录 |
| 字段 | `term`（必填，≤64）、`meaning`（必填，≤300）、`phonetic`、`partOfSpeech`、`example`、`exampleTranslation`、`tags`（≤6，去重） |
| 唯一性 | `term` 不区分大小写唯一；数据清洗同时按 `id` 去重 |
| 增删改 | 重复词条拒绝并提示；删除单词同时清理其卡片、错题与作答记录（二次确认） |
| 搜索 | 匹配 `term` / `meaning` / `tags`，不区分大小写 |
| 筛选 | 全部 / 新词 / 学习中 / 复习中 / 已掌握 / 错词（含筛选计数） |
| 排序 | 最近添加 / 字母序 / 错误最多 / 最先到期 |
| 分页 | 每次渲染 60 条，可「加载更多」 |
| 导入词库 | JSON 数组，或含 `words` 数组的对象；字段非法条目忽略并在预览中提示；重复词条跳过；导入后 toast 报告新增/跳过数量；<br>非法 JSON 时禁用导入按钮并给出格式错误 |
| 导出词库 | 导出纯单词字段（不含学习状态）为 JSON，文件名带日期 |
| 上限 | `MAX_WORDS = 10 000` |

### 3.2 闪卡与间隔重复

| 评分 | 按钮文案 | 首次/学习阶段间隔 | 复习阶段间隔 | 难度系数 |
| --- | --- | --- | --- | --- |
| `again` | 没记住 | 10 分钟后重来，`lapses+1`，状态 `learning` | 同左 | −0.20 |
| `hard` | 有点模糊 | 1 天 | `interval × 1.2` | −0.12 |
| `good` | 记住了 | 2 天 | `interval × ease` | 不变 |
| `easy` | 太简单了 | 4 天 | `interval × ease × 1.3` | +0.10 |

- 难度系数 `ease ∈ [1.3, 3.0]`；单次间隔上限 180 天；间隔 ≥ 30 天状态为 `mastered`；复习 ≥2 次为 `review`。
- 卡片状态：`new`（reps=0）→ `learning`（首次答对/relearn）→ `review` → `mastered`。
- 按钮上展示按当前卡片计算的间隔预览（`10 分钟 / 1 天 / 2 天 / 4 天` 等）。
- 队列：学习中（最早到期优先）→ 到期复习 → 新词；默认每轮 ≤24 张、新词 ≤10；模式：混合 / 只复习 / 只学新词；队列在「开始本轮」时构建一次。
- 快捷键：扉页 `Space`/`Enter` 开局；学习中 `Space` 翻面、`1`–`4` 评分、`Esc` 结束本轮；焦点在按钮/输入框时不劫持空格。
- 未翻面按 `1`–`4`：仅轻提示「先翻面」，不记录评分。
- 复习阶段（relearn 后再次答对）继续按复习公式扩展间隔，避免间隔永远停留在 1–2 天。
- 空状态：全部学完后「再来一轮」→ 空状态 + 提示；空队列提供「去词库添加」与「AI 特训」两个出口。
- 成绩单：本轮正确率（`again` 视为错）、用时、四档次数、需要再看一眼的词；出口「再来一轮 / 去错题 AI 特训 / 回首页」。

### 3.3 错题档案

- 每个词最多一份档案：`wrongCount`、`correctStreak`、`firstWrongAt`、`lastWrongAt`、`lastAttemptAt`、`lastExerciseType`、`lastPrompt`（≤300，供 LLM 避免重复出题）。
- 闪卡 `again` 记为错；`hard` 不改档案；`good`/`easy` 若已有档案则 `correctStreak+1`。
- 练习题判错记为错（含题型与题干）；判对 `correctStreak+1`。
- `correctStreak ≥ 2` 视为「已攻克」，错题本中排在未攻克项之后；侧栏与特训页角标只统计未攻克错词。

### 3.4 AI 错题特训

**选词（setup）**

- 默认候选：错题本按错误次数 desc → 最近出错 desc，默认勾选前 8 个；可全选/清空。
- 无错词：空状态 + 「随机从词库选词」（随机 8 个，标题切换为「这轮抽到的词」）；词库为空：提示先去添加。
- 每个候选展示：词、音标、释义、错误次数、最近出错时间、近期正确率。
- 题量 4 / 6 / 8（默认 6）；难度「自适应 / 巩固基础 / 挑战」（默认自适应）。
- 引擎状态：已配置显示协议 + 模型；远端缺 Key 显示金色提示与「前往设置」；可随时「不用大模型，改用本地题库」。

**生成（generating）**

- 分阶段文案（如「正在整理错词与错因…」「正在校验题目…」）、已用秒数、可取消（取消后回到 setup，无脏状态）。
- 失败：展示 `LLMError.message` + 按 code 的可操作建议 + 服务端摘要；操作「重试 / 改用本地题库继续 / 返回调整」。

**作答（quiz）**

- 选择题：选项 3~4 个，键盘 `1`–`4` 选择、`Enter` 判分、判分后 `Enter` 下一题；填空：行内输入，`Enter` 提交。
- 判分：`normalizeAnswer` 后比较；填空命中 `answer` 或任一 `acceptableAnswers` 即正确。
- 判分后立即显示：对/误、你答与正解、中文解析、考查词（可发音）。
- 每题判分立即写回学习记录（卡片按 `good`/`again` 排程、错题档案与每日统计同步更新），双击/重复点击不会重复计数。
- 可随时「结束特训」，按已答部分结算。

**成绩单（result）**

- 正确率、答对/答错/已答/用时、错题复盘（词、释义、你答、正解）、批语；出口「再练一组（保留上次选词与题量）/ 去闪卡复习 / 回首页」。
- 实际题量少于目标时按实际完成（每词最多 2 题所致），文案需说明。

### 3.5 LLM 出题（`PROMPT_VERSION = v1`）

- 题型：`choice` 词义/辨析、`fill` 例句填空、`usage` 用法判断、`correction` 纠错判断（后两者同为选择题）。
- 出题策略：错误次数多、近期正确率低、连续答对少的词优先；若上次错在某题型，优先再考同类；每词 ≤2 题；干扰项同词性/同语义场、禁止「以上都对」类选项。
- 输出严格纯 JSON；解析层容忍代码围栏与前后杂文。
- 校验：`wordId` 必须在输入内；题型合法；选择题选项 3~4 且互不重复、答案精确匹配（归一化唯一命中时修正、容忍 `A.` 类序号）；填空必须含连续下划线、答案唯一非空；`prompt ≤500`、`explanation ≤400`（超长截断）；`difficulty` 取整并限制 1~5；选项打乱；按 `wordId+type+规范化 prompt` 去重。
- 全部不合法 → 报错（`parse`/`empty`），由 UI 回退本地题库。

### 3.6 本地兜底出题

- 输入：所选单词 + 全库错题档案 + 目标题量；永不抛错，词库不足时返回更少题目（可为 0）。
- 选题：错词按错误次数/最近出错优先，先覆盖尽量多不同单词。
- 选择题：词↔义双向交替；选项取自其他真实词条；同词性、拼写/释义相近优先；释义重叠过高视为近义不采用；`answer` 严格等于某选项原文。
- 填空：在例句中按屈折形式（-s/-ed/-ing/双写/y→ies 等）挖空；`acceptableAnswers` 含原形与大小写变体；例句不可用或一词多现时退化为语境句防泄题。
- 字段：`source='local'`、`difficulty` 2–5（错词次数加权）。

### 3.7 今日仪表盘

- 指标：到期复习数、新词数、今日学习次数（目标 20）、近七日正确率、连续学习天数（今天未学则从昨天往前数）、今日进度条、错题待攻克前 5、词库掌握度四段分布、28 天热力图（1/5/10/20 次分四档）、最近 5 条作答。
- 快捷入口：开始今日学习 / 错题 AI 特训 / 去词库 / 特训指定错词。

### 3.8 设置

- **模型连接**：协议（OpenAI 兼容 / Anthropic）、常用服务预设（OpenAI / DeepSeek / Moonshot / Ollama 本地）、Base URL（自动拼接端点）、模型（可输入 + 建议列表）、API Key（密码框、可切换显示、本地模型可留空）、温度 0–1.5、最大输出 Tokens 64–16000；「测试连接」显示成功/失败、延迟、模型或可操作原因；未保存的草稿与已保存值分离，变更后可保存，导入备份后草稿自动同步。
- **数据管理**：本机占用体积、词条与作答数量；导出完整备份（可选包含 Key，默认关闭并提示风险）/ 导入备份（覆盖词库与记录、保留当前 Key、二次确认）；清空学习进度（保留词库/设置/主题，二次确认）；恢复初始示例词库（保留设置与主题，二次确认）。
- **外观**：昼读/夜读（持久化到数据并作用于 `<html data-theme>`，同步 `theme-color`）。
- **关于**：版本、出题引擎、提示词版本、记忆算法、存储位置、隐私说明。

## 4. 数据与安全规格

- 存储键 `deepword:data:v1`；上限 `MAX_ATTEMPTS = 3000`，每日统计保留 400 天。
- 持久化：数据变化 250ms 防抖写入；页面隐藏/离开前强制落盘。
- 损坏恢复：读取失败时提示一次、把原始文本写入 `deepword:data:v1:corrupt:<timestamp>`、载入示例词库；`words` 存在但类型非法同样按损坏处理。
- 配额满：给出可操作提示（导出备份后清理记录），同一错误不重复刷屏。
- Key 安全：仅存本机；导出默认不含；不出现在 DOM、控制台、URL、异常栈。
- 内容安全：模型输出经严格校验，题干与解析按纯文本渲染（不执行 HTML）。
